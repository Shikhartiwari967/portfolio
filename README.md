# 🚀 Personal Portfolio Website

A modern, sleek, and fully responsive personal portfolio website built with clean HTML, CSS, and JavaScript. Designed with a stylish glassmorphism UI, interactive elements, and custom neon accents to showcase my skills, projects, and contact info.

![Portfolio Preview](img.jpeg)

---

## 🌟 Features

* *Glassmorphism Design:* Modern UI styling with floating cards and subtle gradients.
* *Fully Responsive:* Optimized across mobile, tablet, and desktop screens.
* *Interactive Navigation:* Smooth scrolling across sections.
* *Live Deployment:* Hosted seamlessly on Vercel with automatic GitHub integration.

---

## 🛠️ Tech Stack

* *Frontend:* HTML5, CSS3, JavaScript (ES6+)
* *Icons & Fonts:* Font Awesome, Google Fonts
* *Hosting:* Vercel
